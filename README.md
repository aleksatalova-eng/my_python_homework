# Автоматизированное тестирование веб-приложений

## Описание базового синтаксиса записи и форматирования

Проект содержит UI-тесты для двух различных веб-ресурсов и использует следующие технологии:

1. **Python 3 и аннотации типов (Type Hinting)**: Весь код написан на объектно-ориентированном Python с явным указанием типов данных для аргументов и возвращаемых значений функций (`driver: WebDriver`, `-> None` и т.д.).
2. **Selenium WebDriver (Python binding)**: Используется для автоматизации действий в браузерах Chrome и Firefox, эмуляции действий пользователя и динамического взаимодействия с веб-элементами.
3. **Паттерн Page Object Model (POM)**: Логика интерфейса страниц изолирована от самих тест-кейсов. Каждый экран системы представлен отдельным классом:
   - **Проект 1 (Калькулятор)**: `CalculatorPage` реализует подход *Fluent Interface* (методы возвращают `self`), позволяя строить цепочки вызовов.
   - **Проект 2 (Swag Labs)**: Классы `LoginPage`, `InventoryPage`, `CartPage` и `CheckoutPage` инкапсулируют локаторы элементов (`By.ID`, `By.CLASS_NAME`) и методы работы со страницами магазина.
4. **Фреймворк Pytest и интеграция с Allure**: Тесты организованы в виде функций с префиксом `test_`. Для генерации подробных отчетов используются декораторы, контекстные менеджеры и библиотека `allure-pytest`.

### Правила оформления кода

- Код форматируется в соответствии с PEP 8 (стиль написания кода на Python).
- Используются docstrings для документирования методов и функций.
- Все шаги теста размечаются с помощью `@allure.step` для улучшения читаемости отчетов.

## Запуск тестов и генерация результатов

1. Убедитесь, что виртуальное окружение активировано и в терминале установлены все необходимые зависимости проекта:
   ```bash
   pip install pytest selenium allure-pytest
   ```

2. Вы можете запустить как отдельные тест-кейсы, так и все тесты одновременно, указав флаг для сохранения сырых результатов в общую папку:
   ```bash
   # Запуск всех тестов в проекте
   pytest --alluredir allure-results

   # Запуск только теста калькулятора
   pytest test_calcul.py --alluredir allure-results

   # Запуск только теста магазина Swag Labs
   pytest test_shop.py --alluredir allure-results
   ```
   *После выполнения команд в корневой директории проекта появится папка `allure-results` с файлами отчета в формате JSON.*

## Визуализация отчета Allure

1. Запустите локальный сервер для просмотра папки `allure-results` с помощью одной консольной команды:
   ```bash
   allure serve allure-results
   ```
   *Команда автоматически соберет отчет, запустит веб-сервер и откроет сгенерированную страницу в вашем браузере по умолчанию.*

2. В отчете Allure вы увидите результаты по обоим сценариям:

   ### Тест-кейс №1: Медленный калькулятор
   - название теста: *«Проверка сложения двух чисел с задержкой»*
   - описание теста: *«Тест открывает калькулятор, выставляет задержку в 45 секунд, складывает 7 и 8, после чего ожидает результат 15.»*
   - шаги
     - *Запустить браузер Chrome*
     - *Выполнить математическую операцию: 7 + 8* (включает открытие страницы, установку задержки 45 сек. и клики по кнопкам "7", "+", "8", "=")
     - *Ожидать появление результата '15' на экране калькулятора*
     - *Проверить, что итоговое значение на экране равно '15'*
     - *Закрыть браузер*
   - результат: Успешный статус выполнения сценария (`Passed`), общее время работы (с учетом 45-секундного ожидания калькулятора) и уровень важности `CRITICAL`.

   ### Тест-кейс №2: Интернет-магазин Swag Labs
   - название теста: *«Сквозной сценарий покупки товаров в магазине Swag Labs»*
   - описание теста: *«Тест проверяет полный цикл покупки: авторизацию пользователя, добавление трех товаров в корзину, валидацию количества позиций, заполнение адреса доставки, а также финальную проверку итоговой стоимости заказа.»*
   - шаги
     - *Открытие главной страницы сайта*
     - *Авторизация пользователя с логином: 'standard_user'*
     - *Добавление товара в корзину по идентификатору* (выполняется для каждой из трех позиций)
     - *Переход со страницы каталога в корзину*
     - *Проверка: количество товаров в корзине равно 3*
     - *Заполнение данных доставки: имя 'Александра', фамилия 'Алексеева', индекс '640031'*
     - *Подтверждение информации о доставке (нажатие кнопки Continue)*
     - *Проверка: итоговая стоимость заказа составляет 'Total: $58.29'*
     - *Закрытие сессии веб-драйвера*
   - результат: Успешный статус выполнения сценария (`Passed`), детальная разбивка по времени выполнения каждого шага и уровень важности `CRITICAL`.
